# Cash System Discord Bot

Welcome to the **Cash System Bot**, a comprehensive e-commerce and financial ecosystem built directly into Discord. This bot enables server owners to open their own stores, allowing users to purchase products seamlessly. It also features a robust, cross-server donation and rating system.

## Key Features

* **In-Server E-commerce:** Server owners can easily set up a store, list products, and sell directly to their community.
* **Secure Payments:** Fully integrated with PayPal for safe, instant, and reliable transactions.
* **Global Donation System:** Both regular users and server owners can generate links to send, receive, and track donations.
* **Store Ratings:** A built-in review system allowing buyers to rate their experience, helping stores build credibility.
* **Interactive Web UI & Dashboards:** Visual interfaces for managing products, tracking sales, and monitoring donations.

## Commands & Explanation

* **`/controller`**: Opens the product management control panel. This allows the store owner to add new products, edit existing ones, and manage pricing directly.
* **`/publish my store`**: Publishes the server's storefront into a specified Discord channel, making it accessible for users to browse and purchase.
* **`/donate me`**: Generates a personal donation link for regular users to receive funds from others.
* **`/publish my rate`**: Creates and shares a dedicated link in the channel so customers can rate the server's store.
* **`/rate server`**: Allows users to rate a store directly using a command, without needing to click an external link.
* **`/server donation`**: Generates a dedicated donation link specifically for the server to receive support from its community.
